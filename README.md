# 🛡️ Yatraksha Police & Tourism Dashboard

The **Yatraksha Police & Tourism Dashboard** is a secure, web-based control panel for **tourism department officers** and **police authorities**.  
It enables real-time monitoring, quick response to SOS alerts, and actionable insights for safer tourism.

---

## 🚀 Features

### 👮 Officer Login
- Secure login with **State selection** and **Officer ID**.
- Role-based access (Tourism Officer / Police Officer).

### 🗺 Live Map & Heatmaps
- **Real-time tourist tracking** with geo-fencing zones.
- Visual **heatmaps** of tourist density and high-risk clusters.
- Instant alerts when tourists enter restricted or sensitive areas.

### 🚨 SOS & Emergency Handling
- View **live SOS alerts** raised by tourists.
- **Tourism Department View:** Only sees anonymized tourist ID and basic trip data.
- **Police Department View:** Full access to name, phone number, health vitals, trip itinerary, and last known location.
- **One-Click E-FIR Generation** – automatically logs details on blockchain.
- Record keeping for all alerts and responses.

### 📢 Announcements & Notifications
- Create and broadcast announcements to tourists in a specific region.
- Notify tourists about weather warnings, route closures, or safety guidelines.

### 📊 Analytics & Reports
- Monthly statistics of SOS alerts, resolved incidents, and registered trips.
- Exportable reports for record keeping.
- Visualization of high-risk zones over time.

---

## 🛠 Tech Stack

- **React.js** – Interactive dashboard UI  
- **Tailwind CSS** – Modern, responsive design  
- **Map Libraries** – Live map rendering with clustering & heatmaps  
- **Web3.js / Ethers.js** – Blockchain-backed storage for immutable records  
- **REST APIs / WebSocket** – Real-time updates  

---

## 📸 Key Screens

- **Officer Login** – Secure state & ID-based login  
- **Live Map** – Tourists’ real-time positions with clustering  
- **SOS Alerts Panel** – List + details with priority handling  
- **Announcements** – Create and broadcast safety notifications  
- **Monthly Report** – Incidents, alerts, and E-FIR statistics
